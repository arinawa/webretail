# YanzahNet Retail — Vercel

Website statis siap deploy ke Vercel.

## Cara deploy
1. Ekstrak `yanzahnet-vercel.zip`.
2. Buka https://vercel.com/ lalu login.
3. Pilih **Add New → Project**.
4. Impor repository GitHub yang berisi file `index.html`, atau deploy dengan Vercel CLI dari folder proyek.
5. Untuk website statis ini, Build Command tidak diperlukan. Pastikan `index.html` ada di root proyek.
6. Klik **Deploy**.

Tidak perlu framework atau proses build untuk versi HTML statis ini.
